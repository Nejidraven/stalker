# Stalker Zone

Одиночная 3D-игра от третьего лица в постапокалиптическом сеттинге в духе S.T.A.L.K.E.R.
Движок: **Godot 4.7**, модели: **Blender 5.2**. Сервера нет, всё работает локально.

## Запуск
1. Установить Godot 4.7.
2. Установить Git LFS (`git lfs install`) до клонирования, иначе модели не скачаются.
3. Открыть папку проекта в Godot и нажать F5.

## Управление
| Клавиша | Действие |
|---|---|
| W A S D | движение |
| Shift | бег |
| Пробел | прыжок |
| Мышь | камера |
| E | взаимодействие, подбор |
| Tab | инвентарь |
| G | выбросить предмет |
| V | вид от первого / третьего лица |
| 1 / 2 | пистолет / автомат |
| ЛКМ / ПКМ | стрельба / прицеливание |
| R | перезарядка |
| B | режим огня |
| Ё (`~`) | консоль разработчика: все предметы для перетаскивания в инвентарь |

## Что уже сделано
- Движение, выносливость, здоровье, радиация, аномалии
- Инвентарь с весом, слотами снаряжения и перетаскиванием
- Оружие: пистолет и АК, одиночный и автоматический огонь, мишени
- Тряска камеры, консоль разработчика
